About

These maps show bias-corrected, downscaled 30-day precipitation forecasts for East, West and Southern Africa from the SubC project (https://weather.ou.edu/~kpegion/subc/). A new forecast starts each Thursday; models that arrive later in the week are added as they come in, so a week's maps can change until the following Monday.

The anomaly and percent-of-normal maps compare each forecast with the 1999–2016 observed average for the same calendar days. The observed dataset is named under each map's colour bar.

Models

Which models appear depends on what was available that week; each map labels its panels.

  • NCEP CFSv2 - Climate Forecast System Version 2
  • GMAO GEOS - NASA Global Modeling and Assimilation Office's Goddard Earth Observing System
  • EMC GEFSv12 - Global Ensemble Forecast System v12
  • ECCC GEPS8 - Environment and Climate Change Canada's Global Ensemble Prediction System v8
  • ESRL FIMr1p1 - NOAA ESRL Flow-following finite-volume Icosahedral Model
  • RSMAS CCSM4 - Community Climate System Model 4
